# Midterm report (Vite + React)

Student-facing instructions live in the repository root: [`../README.md`](../README.md).

Quick start:

```bash
npm install
npm run dev
```

Point `src/results.js` at `src/data/<UNI>-midterm-results.json`, validate with
`python3 ../code/export_midterm_results.py src/data/<UNI>-midterm-results.json`
(works from any folder), then push to `main` for GitHub Pages.
